Виджет для iPhone

Пары на сегодня прямо на домашнем экране и экране блокировки. Нужно бесплатное приложение Scriptable.

Сменить

Сначала выбери группу, преподавателя или аудиторию в приложении — выбор подставится в виджет.

Выбрать группу
1

Установи Scriptable

Бесплатное приложение из App Store.

Открыть в App Store
2

Скопируй скрипт

В нём уже твой выбор и напоминание за 5 минут до пары.

3

Вставь в Scriptable

Открой Scriptable → + (справа сверху) → вставь скрипт → нажми на название сверху и назови «Расписание» → Готово. Нажми ▶︎, чтобы проверить.

4

Добавь виджет

Долгое нажатие на пустом месте экрана → Править → Добавить виджет → Scriptable → выбери размер (лучше средний или большой) → Добавить. Затем нажми на виджет → Script → «Расписание».

Для экрана блокировки: зажми экран блокировки → Настроить → виджеты → Scriptable → тот же скрипт.

Виджет сам обновляется в начале и конце каждой пары (iOS может немного задерживать обновления). Без интернета показывает последнюю сохранённую копию. Нажатие на виджет открывает сайт.
