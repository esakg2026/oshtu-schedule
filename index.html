Какая неделя сейчас
На сайте ОшТУ ячейка делится линией: сверху — верхняя неделя, снизу — нижняя. Недели чередуются автоматически.

Виджет на главный экран
Android: скачай приложение — в нём есть настоящий виджет «Пары сегодня» с кнопками ‹ ›. После установки открой приложение, выбери группу, затем: долгое нажатие на пустом месте экрана → Виджеты → «Расписание для студентов ОшТУ».
Скачать приложение для Android (APK)
Телефон спросит разрешение на установку из браузера — разреши для Chrome.
iPhone: виджет на домашний экран и экран блокировки через бесплатное приложение Scriptable — настройка за 1 минуту.
Настроить виджет для iPhone
Долгое нажатие на пустом месте рабочего стола → Виджеты → найди «Расписание для студентов ОшТУ» → перетащи на экран. В виджете: ‹ › — другой день, нажатие на заголовок — вернуться к сегодня, на строку «обновлено» — обновить.
Веб-виджет (для iPhone и других приложений)
Открыть веб-виджет →
iPhone: Safari → «Поделиться» → «На экран Домой».
